개인정보처리방침

시행일: 2026년 10월 14일

Car Comment Insights(이하 "본 도구")는 윤석진(이하 "운영자")이 개인적으로 운영하는 내부 분석 도구입니다. 본 방침은 본 도구가 YouTube API 서비스를 통해 얻는 정보를 어떻게 다루는지 설명합니다.

1. YouTube API 서비스 사용

본 도구는 YouTube API 서비스를 사용합니다. 본 도구를 이용하거나 본 도구가 제공하는 정보를 열람하는 경우 YouTube 서비스 약관이 적용되며, YouTube API 서비스를 통해 처리되는 정보에는 Google 개인정보처리방침이 적용됩니다.

2. 수집하는 정보

  • 공개 채널 정보: 채널명, 채널 ID, 구독자 수, 영상 수
  • 공개 영상 정보: 영상 ID, 제목, 게시일, 조회수·좋아요 수·댓글 수
  • 공개 최상위 댓글: 댓글 본문, 좋아요 수, 게시일

본 도구는 로그인(OAuth)을 사용하지 않으며, 이용자의 Google 계정 정보, 비공개 데이터, 기기 정보, 쿠키를 수집하지 않습니다. 댓글 작성자의 이름·프로필 등 신원 정보는 저장하지 않습니다.

3. 이용 목적

수집한 정보는 영상별·브랜드별로 언급 브랜드, 언급 주제, 구매·시승 의향, 긍정·부정 반응 건수를 집계하는 데만 사용합니다. 집계 결과는 운영자의 미디어 기획 연구용으로만 활용하며, 개별 댓글이나 작성자 정보는 화면에 표시하거나 제3자에게 제공·판매하지 않습니다.

4. 보관 및 삭제

  • YouTube API로 받은 원본 데이터(댓글 본문, 영상 제목 등)는 수집일로부터 30일 이내에 새로 고치거나 삭제합니다.
  • 개인을 식별할 수 없는 집계 통계(예: 영상별 브랜드 언급 건수)는 YouTube 개발자 정책이 허용하는 범위 내에서 보관합니다.
  • 데이터는 운영자 개인 컴퓨터에 저장되며 외부 서버에 업로드하지 않습니다.

5. 삭제 요청 및 권한 철회

본인 댓글이 집계에 포함되는 것을 원하지 않거나 관련 데이터 삭제를 원하시면 아래 연락처로 요청해 주세요. 7일 이내에 해당 데이터를 삭제합니다. 본 도구는 이용자 계정 권한을 요청하지 않지만, Google 계정에 연결된 앱의 권한은 언제든지 Google 보안 설정 페이지에서 확인·철회할 수 있습니다.

6. 제3자 제공

운영자는 수집한 정보를 제3자에게 제공, 공유, 판매하지 않습니다.
