1. 서비스

Car Comment Insights(이하 "본 도구")는 공개된 자동차 관련 영상 데이터를 집계해 보여 주는 개인용 분석 도구입니다. 본 도구는 운영자 개인이 내부적으로만 사용하며, 일반에 판매하거나 유료로 제공하지 않습니다.

2. 데이터 출처 및 약관

본 도구를 이용하는 것은 YouTube 서비스 약관에 동의하는 것을 의미합니다. 본 도구가 표시하는 정보는 YouTube API 서비스에서 제공받은 것이며, YouTube 콘텐츠에 대한 권리는 각 권리자에게 있습니다.

3. 금지 사항

  • 본 도구의 데이터를 이용해 개인을 식별하거나 추적하는 행위
  • 본 도구에서 얻은 원본 데이터를 재배포·판매하는 행위
  • 데이터 제공자의 약관 및 개발자 정책을 위반하는 방식의 이용

4. 개인정보

정보 처리에 관한 내용은 개인정보처리방침과 Google 개인정보처리방침을 따릅니다.

5. 면책

본 도구의 분석 결과는 자동 분류에 기반한 참고 자료이며, 정확성이나 완전성을 보증하지 않습니다.
