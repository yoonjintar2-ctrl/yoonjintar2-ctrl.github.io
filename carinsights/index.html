자동차 유튜브 댓글 인사이트

한국어 자동차 관련 유튜브 채널의 공개 댓글을 집계해, 영상별로 어떤 브랜드·차종이 언급되는지, 디자인·가격·성능 등 어떤 주제로 이야기되는지, 구매·시승 의향과 긍정·부정 반응이 어떤지를 보여 주는 개인용 분석 도구입니다.

무엇을 하나요

YouTube Data API v3의 공개 데이터(채널·영상 통계·최상위 공개 댓글)만 읽기 전용으로 사용합니다. 로그인(OAuth)이 없고 비공개 데이터에는 접근하지 않습니다.

무엇을 보여주나요

영상·브랜드 단위의 집계 수치만 표시합니다. 개별 댓글 원문이나 작성자 정보는 화면에 노출하거나 외부에 배포하지 않습니다.

데이터 보관

API로 받은 원본 데이터는 30일 이내에 갱신하거나 삭제하며, 개인을 식별할 수 없는 집계 통계만 보관합니다. 자세한 내용은 개인정보처리방침을 확인하세요.
